# 攝影相簿展示

使用 Python 3.11 以上即可啟動，目前應用程式與測試僅使用標準函式庫。相簿來源採唯讀存取，未列入中央設定的資料夾一律不發佈。

## 啟動

在專案目錄建立設定，並指定相簿根目錄：

```sh
cp config/albums.example.json config/albums.json
python3 app.py --albums-root '/path/to/Albums'
```

開啟 `http://127.0.0.1:8000/`。空白設定會顯示「目前尚無公開相簿」。可使用 `--host` 與 `--port` 指定監聽位置與連接埠；預設僅允許本機連線。此專案不包含正式部署或 NAS 掛載設定。

設定位置固定為**啟動工作目錄**內的 `config/albums.json`，不是依來源根目錄或程式檔案位置尋找。請在專案根目錄執行；若要隔離部署設定，也可從另一個含有 `config/albums.json` 的工作目錄執行程式的完整路徑。這個設定檔已排除於 Git，請勿提交私人來源名稱。

設定使用 UTF-8 JSON，例如：

```json
{
  "version": 1,
  "albums": [
    {
      "folder": "2025 台北散步",
      "slug": "taipei-walk-2025",
      "title": "台北散步",
      "date": "2025-03-15",
      "status": "public",
      "cover": "photo2.jpg"
    }
  ]
}
```

這本相簿固定讀取 `Albums/2025 台北散步/output/` 第一層的 JPG／JPEG；副檔名不分大小寫，RAW、其他檔案與子資料夾不納入相片數。`folder` 必須是單層名稱。相片依檔名做不分大小寫的自然排序，數字按數值比較，相等時依原始檔名決定順序。`cover` 可省略，預設使用排序後第一張；指定時須符合實際檔名大小寫。

`slug` 僅接受小寫英文字母、數字與連字號。`title` 去除頭尾空白後不得為空，可同名；`date` 是有效的西元 `YYYY-MM-DD`，允許未來日期。`public` 會出現在首頁，`unlisted` 不列入首頁，`disabled` 不發佈。停用相簿仍須通過欄位驗證，但無須保留來源或封面。

未知欄位、重複 `folder`／`slug`、錯誤型別、版本或不合法值均會阻止啟動。任一本已發佈相簿缺少來源、第一層 JPG 或指定封面時，整個應用程式回報錯誤並退出，不會部分發佈。設定更動後請重新啟動。

## 測試

```sh
python3 -m unittest discover -s tests -v
```

測試以暫存來源與設定啟動真實應用程式，觀察程序退出與 HTTP 回應；不讀取私人 NAS。合成 JPG 測試資料已隨專案提供。涵蓋中央白名單、設定型別與值、日期排序與相片計數、來源及封面缺漏、連結越界、停用免來源、空列表、唯讀來源與未提供入口的 404。執行環境必須允許建立本機 HTTP 連線。
